Połącz z GitHub

Wprowadź Fine-grained Personal Access Token. Token musi mieć dostęp do repozytorium kac0pi oraz uprawnienie Contents: Read and write.

Jak utworzyć token?

  1. Otwórz GitHub Tokens .
  2. Wybierz Fine-grained token.
  3. Wybierz repozytorium kac0pi.
  4. Ustaw Contents → Read and write.
  5. Wygeneruj token i skopiuj go.

Nie udostępniaj tokenu. Nie umieszczaj go w plikach strony. Panel przechowuje go tylko w pamięci karty przeglądarki.
