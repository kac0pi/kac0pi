Połącz z GitHub

Wklej token GitHub z uprawnieniem Contents: Read and write dla repozytorium kac0pi.

Jak utworzyć token?

  1. Otwórz GitHub Tokens .
  2. Wybierz Fine-grained token.
  3. Wybierz repozytorium kac0pi.
  4. Ustaw Contents → Read and write.
  5. Utwórz token i skopiuj go.

Nie udostępniaj tokenu. Nie umieszczaj go w kodzie ani publicznym repozytorium. Panel nie zapisuje tokenu w LocalStorage.
